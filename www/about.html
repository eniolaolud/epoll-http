epoll-http

About this demo

A small Linux HTTP/1.1 server using non-blocking sockets and epoll.

Features

  • Concurrent client I/O via edge-triggered epoll
  • Static files from www/
  • Cookies (Set-Cookie / Cookie)
  • Multipart and raw POST uploads
  • DELETE for files under www/uploads/
  • CGI scripts under cgi-bin/
